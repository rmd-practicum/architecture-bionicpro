# Задание 2

## Задача 1

[Архитектурное решение](./Task2/BionicPRO_C4_model.drawio) обновлено. Новые компоненты выделены зеленым цветом.

## Задача 2

Добавлены сервисы Airflow и Clickhouse, [файл DAG](./airflow/dags/dag.py). Данные для демонстрации загружаются из [airflow/data](./airflow/data). Витрина собирается ежедневно, один раз в день: это позволит снизить нагрузку на систему, но в то же время предоставлять пользователям достаточно актуальные отчеты.

## Задача 3

Создан [сервис API](./bionicpro-api). API позволяет получить отчет на заданную дату и возвращает статус 404, если данные недоступны.

## Задача 4

Чтобы ограничить доступ к отчетам, предоставим отчеты только авторизованному пользователю; идентификатор пользователя берем из верифицированного токена, выданного и подписанного Keycloak.

## Задача 5

Обновлена [страница фронтенда](./frontend/src/components/ReportPage.tsx).

# Задание 3

Добавлены сервисы minio и nginx для эмуляции CDN. Добавлен [конфигурационный файл nginx](./cdn/default.conf.template). Используется механизм nginx `secure_link` для ограничения доступа к данным (файл отчета можно получить только по ссылке, подписанной нашим API).

Обновлен сервис API: сначала данные для отчета ищутся в объектном хранилище, и только если их там нет — загружаются из OLAP БД, после чего кэшируются. Чтобы упростить использование API, на фронтенд всегда возвращается ссылка на кэшированные данные.

# Залание 4

Добавлены сервисы kafka и debezium connect. Обновлена [конфигурация Clickhouse](./clickhouse/init/01_schema.sql): настроено обновление данных и создана новая витрина.
